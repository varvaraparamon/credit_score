# Система кредитного скоринга

**Спринт №1:** Разработка MVP (Minimum Viable Product)

## 1. Описание проекта

Целью проекта является разработка веб-сервиса для автоматизации процесса принятия решения по кредитным заявкам. Система позволяет пользователю ввести данные заемщика через веб-форму, после чего обученная модель машинного обучения выполняет скоринг и возвращает результат (рекомендацию по выдаче кредита).

В рамках первого спринта планируется реализовать минимально жизнеспособный продукт (MVP), демонстрирующий полный цикл работы сервиса: от ввода данных до получения предсказания.

## 2. Функциональные возможности (MVP)

*   Заполнение анкетных данных заемщика в веб-форме.
*   Отправка данных на серверную часть (API).
*   Валидация входящих данных на стороне бэкенда.
*   Загрузка предобученной модели машинного обучения.
*   Получение скорингового балла и бинарного решения ("Одобрено"/"Отказано").
*   Отображение результата пользователю на той же странице.

## 3. Технологический стек

*   **Язык программирования:** Python 3.9+
*   **Машинное обучение и анализ данных:** Pandas, NumPy, Scikit-learn, Jupyter Notebook
*   **Бэкенд (API):** Flask
*   **Фронтенд:** HTML5, CSS3, JavaScript
*   **Форматирование и версионирование:** Git, .gitignore, README.md
*   **Сериализация моделей:** Joblib / Pickle
*   **Тестирование:** Pytest
